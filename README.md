# Blog App  

A simple Blog App built with Bootstrap, HTML, CSS, and JavaScript.  

## 🚀 Tech Stack
- HTML, CSS, JavaScript  
- Bootstrap (UI)  
- JSON Server (for mock API)  

## ✨ Features
- Add, edit, delete blogs  
- History of deleted blogs  
- Search blogs by title  
- Filter blogs by status (done/active) or tags
